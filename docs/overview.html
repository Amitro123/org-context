org-context — מה המערכת עושה מקצה לקצה

סורק מקומי מאובטח של ריפוזיטוריז ותתי-תיקיות מונוריפו אל SQLite, שמגיש לסוכני קוד (Cursor / Claude) מפת תלויות, CI ו-Capabilities מבוססת ראיות — בלי רשת, בלי הרצת קוד ובלי חשיפת תוכן בברירת מחדל.

מה org-context כן נותן עכשיו

  • איתור Capabilities ואחריות: חיפוש לפי שאילתה (`find_capabilities`) שמחזיר entrypoints, קבצי תיעוד, גבולות `out_of_scope` וסטטוס תצפית (`observed_local_file` / `missing_file`) עם SHA256 נפרד למניפסט ולקובץ.
  • מיפוי תלויות ושימוש חוזר: מציאת חבילות Python/npm מוצהרות והשוואת גרסאות/סקופים בין שורשים (`find_projects_using`, `shared_dependencies`) עם פאגינציה מלאה.
  • תמיכה ב-Monorepo: זיהוי `git_root_relation` (`repository_root` מול `subdirectory`) ו-`git_relative_prefix` (כולל שמירה על רווחים בשם התיקייה) כדי לא לערבב תת-תיקייה עם ריפו עצמאי.
  • הפניות CI מבוקרות: חילוץ `template:` ו-`resources.repositories` מ-Azure Pipelines תוך החרגת `parameters`, מפתחות עם מרכאות, block scalars והערות YAML, ותמיכה בעטיפות `${{ if/each }}`.
  • עקביות Snapshot מלאה: כל קריאת `project_card` מתבצעת ב-SQLite `SAVEPOINT` אחד — אין ערבוב בין ראיות חדשות להפניות ישנות גם תחת סריקה מקבילה.

מה org-context במפורש לא עושה

  • לא שער אבטחה, Eval או אישור פרסום: לעולם לא מחליף Security Gate, Eval Gate, `enterprise-review` או החלטה אנושית.
  • לא הוכחת Runtime או Deployment: תלות מוצהרת או Git HEAD אינם מוכיחים מה רץ בפרודקשן או האם pipeline עבר.
  • לא מדליף תוכן מסמכים בברירת מחדל: גופי README/CODEOWNERS/CLAUDE.md מוסתרים עד הפעלה מפורשת של `--evidence-pages`, וגופי קבצי קוד שצוינו ב-manifest לעולם לא נשמרים.
  • לא מריץ קוד ולא מתחבר לרשת: אין קריאות API ל-Azure/GitHub, אין LLM בתוך השרת, ואין הרצת סקריפטים מהריפוזיטוריז הנסרקים.
  • לא פותר סמלים סטטית: שדה `symbol` ב-manifest מסומן תמיד כ-`declared_only_not_resolved`.

4. פקודות הפעלה מהירה (מקומי)

# 1. סריקת ריפוזיטוריז או תתי-תיקיות מאושרות של מונוריפו
python -m org_context.cli --db pilot.sqlite scan /approved/monorepo /approved/monorepo/modules/evaluation

# 2. הצגת השורשים שנסרקו
python -m org_context.cli --db pilot.sqlite list

# 3. הרצת שרת ה-MCP לקריאה בלבד (ברירת מחדל: מטא-דאטה בלבד, 6 כלים)
python -m org_context.mcp_server --db pilot.sqlite
